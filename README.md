# Smart Crop Recommendation System

## Project Overview
I built this machine learning application to help farmers and agricultural enthusiasts make data-driven decisions.
By analyzing soil nutrients and environmental factors, this app recommends the most optimal crop to plant, taking the guesswork out of farming.

**The Tech Stack:**
* **Language:** Python
* **Machine Learning:** Scikit-Learn
* **Data Manipulation:** Pandas & NumPy
* **Web Framework:** Streamlit
